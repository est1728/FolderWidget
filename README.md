# Folder Widget (โฟลเดอร์วิตเจ็ต)

โปรเจกต์ Android Studio พร้อม build เป็น .apk เอง

## วิธี build เป็น .apk

1. เปิด Android Studio (เวอร์ชันล่าสุด แนะนำ)
2. เลือก **Open** แล้วชี้ไปที่โฟลเดอร์ `FolderWidget` นี้ทั้งโฟลเดอร์ (ไม่ใช่ไฟล์เดี่ยว)
3. รอ Gradle sync เสร็จ (ครั้งแรกอาจโหลด dependency สักพัก ต้องมีเน็ต)
4. เมนู **Build > Build Bundle(s) / APK(s) > Build APK(s)**
5. ได้ไฟล์ที่ `app/build/outputs/apk/debug/app-debug.apk`
6. โอนไฟล์ apk เข้า Redmi Pad 2 แล้วติดตั้ง (เปิด "อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก" ก่อน)

## วิธีใช้งานในเครื่อง

1. กดค้างที่หน้าโฮม > Widgets > หา "Folder Widget"
2. ลากวางลงจอ → จะเด้งไปหน้า **"แก้ไขโฟลเดอร์"** ให้ตั้งชื่อ, เลือกขนาด (ปกติ/ขยาย/XXL), ติ๊กเลือกแอพที่จะใส่
3. กดปุ่มถูก (✓) มุมขวาบน → widget ปรากฏบนจอ ขนาดกะทัดรัด โชว์ไอคอนพรีวิว 4 อันแรก
4. แตะที่ widget → popup โปร่งใสผุดขึ้นมาแสดงไอคอนทั้งหมดในโฟลเดอร์
5. ในหน้า popup:
   - แตะไอคอนแอพ = เปิดแอพนั้น
   - **กดค้างแล้วลาก** = จัดเรียงลำดับใหม่
   - **ปัดขึ้น** ที่ไอคอนไหน = ลบออกจากโฟลเดอร์
   - แตะพื้นที่นอกการ์ด = ปิด popup กลับไปหน้าโฮม
6. อยากแก้ไขรายชื่อ/ชื่อ/ขนาดใหม่ทั้งหมด: ลบ widget ออกแล้ววางใหม่ (หรือแจ้งผมเพิ่มปุ่ม "แก้ไข" ในหน้า popup ทีหลังได้)

## เลือกได้ 2 แบบวิตเจ็ต

ตอนกดค้างหน้าโฮม > Widgets > ค้นหา "Folder Widget" จะเจอ 2 ตัวให้เลือก:

1. **โฟลเดอร์ (จำกัดตามขนาด)** — ของเดิม ลากรีไซส์ได้ โชว์ 4/9/16 แอพตามขนาดที่ลาก
2. **โฟลเดอร์ (ไม่จำกัดจำนวน)** — ใส่แอพกี่ตัวก็ได้ตอนตั้งค่า แต่บนหน้าโฮมโชว์แค่:
   - 3 ไอคอนแอพแรกแบบเต็มขนาด
   - ช่องที่ 4 เป็น "ไอคอนรวม" — ถ้ามีมากกว่า 4 แอพ จะย่อไอคอนที่เหลือ (สูงสุด 4 ตัว) มาเรียงเป็นกริดเล็กในช่องเดียว ดูคล้ายโฟลเดอร์ซ้อนแอพ
   - แตะ widget → popup เปิดขึ้นมาโชว์ครบทุกแอพ เลื่อนดูได้ถ้ามีเยอะ ลากจัดเรียง/ลบได้เหมือนเดิม
   - ขนาด widget คงที่ ไม่ต้องลากรีไซส์ (ดีไซน์ตายตัวเป็น 2×2)

## รองรับลากปรับขนาด (Resizable Widget) — เฉพาะโฟลเดอร์แบบ "จำกัดตามขนาด"

ตัว widget ลากขยาย/ย่อบนหน้าโฮมได้ (กดค้างที่ widget แล้วลากจุดขอบ) และจะ**สลับเลย์เอาต์ให้เองอัตโนมัติ**ตามขนาดที่ลาก:

| ขนาดที่ลาก (dp) | เลย์เอาต์ที่ใช้ | จำนวนไอคอนพรีวิวสูงสุด |
|---|---|---|
| เล็กกว่า 140dp | `widget_folder_small` (2×2) | 4 |
| 140–219dp | `widget_folder_medium` (3×3) | 9 |
| 220dp ขึ้นไป | `widget_folder_large` (4×4) | 16 |

ตัวเลข threshold (140 / 220) ปรับได้ที่ `FolderWidgetProvider.kt` ฟังก์ชัน `pickLayout()` — ถ้าลองบนแท็บเล็ตแล้วรู้สึกว่าขนาดสลับเร็ว/ช้าเกินไป แจ้งได้ ปรับตัวเลขให้ใหม่

ค่า `maxResizeWidth/Height` ใน `widget_folder_info.xml` กำหนดเพดานว่าลากขยายได้ใหญ่สุดแค่ไหน (ตอนนี้ตั้งไว้ 360dp)



- `FolderWidgetProvider.kt` — ตัว widget บนหน้าโฮม (วาด mini-icon, ตั้ง tap intent)
- `FolderConfigActivity.kt` — หน้าตั้งค่าตอนวาง widget ครั้งแรก (เลือกแอพ+ขนาด เหมือนภาพ MIUI)
- `FolderPopupActivity.kt` — หน้า popup โปร่งใสที่ผุดขึ้นมาตอนแตะ widget (ลากจัดเรียง/ลบ/เปิดแอพ)
- `PrefsHelper.kt` — เก็บข้อมูลแต่ละโฟลเดอร์ลง SharedPreferences
- `AppRepository.kt` — ดึงรายชื่อ/ไอคอนแอพทั้งหมดในเครื่อง

## ปรับแต่งเพิ่มเติมที่ทำได้ทีหลัง

- ขนาด mini-icon / จำนวนคอลัมน์ใน popup: แก้ที่ `FolderPopupActivity.kt` (ตัวแปร `columns`)
- สี/ความโค้งของกรอบ widget: แก้ `res/drawable/bg_folder_card.xml`
- ความเร็ว animation ตอนเปิด/ปิด popup: แก้ `res/anim/popup_enter.xml` และ `popup_exit.xml`
- เพิ่มปุ่ม "แก้ไข" ในหน้า popup เพื่อเรียก `FolderConfigActivity` ซ้ำได้ทุกเมื่อ (ตอนนี้ต้องลบ-วางใหม่)

## Animation ตอนกดวิตเจ็ต

ปกติ Android จะเล่น animation เปิดแอพมาตรฐานของระบบ/launcher ก่อน (ไอคอนขยายเต็มจอ) แล้ว popup ของเราค่อยเด้งซ้อนทีหลัง ซึ่งจะดูเหมือน "เปิดแอพ 2 ชั้น" ไม่เนียน

โค้ดตอนนี้แก้แล้วโดยฝัง animation ผ่าน `ActivityOptions.makeCustomAnimation()` เข้าไปใน `PendingIntent` ที่ widget ยิงตอนถูกแตะโดยตรง (ดูใน `FolderWidgetProvider.kt` และ `FolderStackWidgetProvider.kt`) — วิธีนี้บังคับให้เล่น scale+fade ของเราแทน animation มาตรฐานตั้งแต่ต้น ไม่ใช่แค่ตั้งใน theme เฉยๆ ผลคือกดแล้วจะรู้สึกเหมือนโฟลเดอร์ "ผุด" ขึ้นมาโดยตรง ไม่มีอาการเปิดแอพเด้งสไลด์ก่อน

ถ้า build แล้วลองบน Redmi Pad 2 ยังรู้สึกมี animation ระบบแทรกอยู่ (บาง custom launcher เช่น HyperOS อาจมี override เพิ่มเติมที่ layer launcher เอง ซึ่งควบคุมจากแอพเราไม่ได้ 100%) แจ้งมาได้ จะลองปรับความเร็ว/ค่า pivot ของ animation เพิ่มให้กลบให้เนียนที่สุดเท่าที่ทำได้
